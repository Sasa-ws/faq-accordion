# FAQ Accordion

A responsive and accessible FAQ accordion component built with semantic HTML, CSS, and JavaScript.

## Features

- Responsive layout for desktop and mobile screens
- Semantic HTML structure
- Accessible accordion controls
- Keyboard-friendly buttons
- Visible focus states
- Expandable FAQ sections with chevron indicators
- Detailed FAQ content
- Simple and maintainable CSS
- No page builder used
- Git version controlled through GitHub

## Technologies

- HTML5
- CSS3
- JavaScript
- Git / GitHub

## Accessibility

The component uses:

- Semantic HTML elements
- Native `<button>` elements for interactive controls
- `aria-expanded` to communicate the accordion state
- `aria-controls` to connect questions with their answers
- `role="region"` for answer sections
- `aria-hidden="true"` for decorative chevron icons
- Visible `:focus-visible` styles for keyboard users

## Responsive Design

The layout adapts to smaller screens using CSS media queries. Spacing and typography are adjusted for mobile devices to maintain readability and usability.

## AI-Assisted Development

AI tools were used to assist with code structure, styling ideas, accessibility considerations, and troubleshooting.

All generated code was reviewed, tested, and adjusted manually before being included in the project.

## Git Version Control

The project is version controlled using GitHub. Changes were committed throughout development to track updates to the HTML, CSS, and JavaScript files.
